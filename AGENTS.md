# Repository Agent Instructions

For every implementation, review, refactor, test, contract, configuration, behavior, or architecture task in this repository, load and follow `.agents/skills/proactive-engine-development/SKILL.md` before acting.

The hard boundaries in `ARCHITECTURE.md` are acceptance criteria. If a requested change violates one, explain the conflict and propose a compliant port, adapter, contract, or ADR-based alternative.

Keep work reproducible and Git-managed. Preserve user changes, run the checks relevant to the change, and report skipped validation explicitly.
